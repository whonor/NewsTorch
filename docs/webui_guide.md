# NewsTorch Web UI 使用说明

## 简介

NewsTorch Web UI 是一个基于Flask的图形界面，允许用户通过网页界面选择不同的模型和数据集进行训练、验证和测试，而无需修改项目中的其他代码。

## 安装依赖

在运行Web UI之前，请确保安装了必要的依赖：

```bash
pip install flask flask-wtf
```

## 启动Web UI

1. 在项目根目录下运行以下命令启动Web服务：

```bash
python run_webui.py
```

2. 打开浏览器，访问 `http://localhost:5000` 即可使用Web UI。

## 功能说明

### 训练模型

1. 在Web UI中选择"训练"模式
2. 从下拉菜单中选择要训练的模型和数据集
3. 设置Batch Size和Epoch参数
4. 点击"开始训练"按钮启动训练任务

### 验证模型

1. 在Web UI中选择"验证"模式
2. 从下拉菜单中选择模型和数据集
3. 输入预训练模型的路径
4. 点击"开始验证"按钮启动验证任务

### 测试模型

1. 在Web UI中选择"测试"模式
2. 从下拉菜单中选择模型和数据集
3. 输入预训练模型的路径
4. 点击"开始测试"按钮启动测试任务

## 注意事项

- 训练、验证和测试任务会在后台运行，不会阻塞Web界面
- 请确保选择的模型和数据集组合是支持的
- 模型路径需要是相对于项目根目录的完整路径
